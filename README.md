# Анализ рынка недвижимости СПб: SQL-аналитика и интерактивный дашборд в Yandex DataLens.
## 🛠 Технологический стек:
*   **Хранение данных:** PostgreSQL (схемы, индексы, агрегации).
*   **Аналитика:** SQL (CTE, оконные функции, сегментация).
*   **Визуализация:** Yandex DataLens.

## Решаемые задачи: 
В первой задаче выделены периоды жизни объявлений в разрезе Санкт-Петербурга и области, чтобы понимать где быстрее продаются квартиры и с какими параметрами. Предварительно, использовала процентили (PERCENTILE_DISC) для исключения аномальных объектов. 
Во второй задаче сравниванию поведение рынка в момент открытия продажи квартиры и в момент закрытия в разрезе месяца. Выявила самые активные/неактивные месяцы для продажи и по какой итоговой цене продаются квартиры. 
В третьей задаче определяю ликвидность объектов недвижимости по Ленинградской области. С помощью типа сделки (быстрые и долгие продажи), доли проданных квартир и средней цене за квадратный метр отвечаю на вопрос какие квартиры продаются быстрее и в каких городах/поселках. Какой сегмент продается хуже всего. В ТОП-15 вошли города с количеством квартир в продаже от 58. Это значение соответствует границе, выше которой сосредоточено 90% всех объявлений. Для них выборка репрезентативна, а средние показатели — статистически достоверны.
