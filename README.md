# Анализ рынка недвижимости СПб: SQL-аналитика и интерактивный дашборд в Yandex DataLens.
## 🛠 Технологический стек:
*   **Хранение данных:** PostgreSQL (схемы, индексы, агрегации).
*   **Аналитика:** SQL (CTE, оконные функции, сегментация).
*   **Визуализация:** Yandex DataLens.

## Решаемые задачи: 
В первой задаче выделены периоды жизни объявлений в разрезе городов, чтобы понимать в каких городах быстрее продаются квартиры и с какими параметрами. Предварительно, использовала процентили (PERCENTILE_DISC) для исключения аномальных объектов.
